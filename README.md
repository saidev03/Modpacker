**PackCraft Web Studio Pro (v2.0)** es una suite web profesional para la creación y gestión de modpacks de Minecraft en formato oficial `.mrpack`. Diseñada específicamente para ser **ultraligera, sin necesidad de instalación de launchers ni entornos pesados**, 100% compatible con navegadores en Chromebooks, Linux y PCs de bajos recursos.

---

## 🔥 Novedades de la Versión Pro 2.0

- 🛠️ **Soporte Multi-Loader Total:** Elige libremente entre **Fabric, Forge, NeoForge y Quilt**.
- 📁 **Gestor Avanzado de Overrides (Archivos Locales):** Arrastra carpetas completas (`config/`, `resourcepacks/`, `shaderpacks/`, `defaultconfigs/`) o archivos `.jar` locales para empaquetados directos dentro de `/overrides/`.
- ⚙️ **Ajustes Pro y Metadatos Extendidos:** Configura versiones específicas del Loader, resúmenes personalizados, entorno (Cliente/Servidor) y compatibilidad de Java.
- 🎨 **Interfaz Glassmorphic por Pestañas:** Organización limpia del flujo de trabajo sin saturar la pantalla.
- 📥 **Exportación al Vuelo de `.mrpack`:** Generación binaria instantánea mediante `JSZip` client-side.

---

## 🚀 Guía de Uso

1. **Configuración General:** Selecciona la versión de Minecraft (ej. `1.20.1`) y el Mod Loader deseado en la pestaña **⚙️ General**.
2. **Subida de Configs (Opcional):** Ve a la pestaña **📁 Configs / Overrides** y arrastra la carpeta `config/` o tus packs de recursos.
3. **Búsqueda de Mods:** Utiliza el buscador integrado para agregar mods desde la base de datos oficial de Modrinth.
4. **Exportación:** Haz clic en **📥 Exportar .mrpack**. El archivo resultante está listo para importarse en la app de Modrinth, Prism Launcher, ATLauncher o publicarse directamente en Modrinth.
